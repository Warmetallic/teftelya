# Арт тем: картинки фонов

Для кухни, духовки, погреба и пиршественного зала игра загружает по одному файлу `scene.webp`.
Выбор зафиксирован 30 сентября в [карте прогрессии, §8](../../docs/specs/2026-09-30-progression-map.md) и в верхнем ряду листа `shots/design_palette_round4.png`.

| Башня | Сцена | Исходник в архиве sd-local |
| --- | --- | --- |
| 1 | Кухня с кирпичной стеной, медью и плитой | `out/sc_kitchen_901.png` |
| 2 | Холодильник со стеклянными полками | Задняя стенка `out/back3_400.png`, предметы v2.2c в `fridge/` |
| 3 | Внутри духовки | `out/sc_oven_913.png` |
| 4 | Погреб, вариант D | `chosen/cellar_back.png` |
| 5 | Пиршественный зал, таверна первой пробы | `out/sc_feast_931.png` |

Все четыре цельные сцены отображаются из WebP 832 × 1216. Для кухни и духовки прежний цвет задника перенесён в экспорт из исходного PNG. По каждому каналу применяется `linear` с множителем `коэффициент §8 × 0.84 × (1 − a)` и смещением `цвет × a`. Для кухни цвет RGB (50, 57, 62) и a = 0.38, для духовки (49, 44, 48) и a = 0.40. Параметры WebP — качество 92 и `smartSubsample`.

Стенка холодильника экспортируется из исходного PNG 832 × 1216 в sRGB с теми же параметрами WebP. Предметы собираются на отдельном слое 800 × 4000. Голубое освещение, пар и движение слоёв задаёт `src/art.js`.

Погреб и зал используют полноразмерные WebP 832 × 1216. Для повторного экспорта из PNG в таблице используются sRGB, `sharp.modulate({saturation})`, затем `linear` с коэффициентами RGB из §8, умноженными на 0.84 и дополнительную экспозицию. Для погреба насыщенность 0.89 и экспозиция 0.90, для зала 0.76 и 0.86. Экспорт идёт напрямую в WebP с качеством 92 и `smartSubsample`. Игра показывает готовую текстуру с обычным масштабированием под экран.
В каталоге также сохранены пробы прежней версии. Состав изображений для игры определяет `ART_SRC` в `src/art.js`.

Откуда картинки: сгенерированы локально владельцем (Stable Diffusion XL, чекпоинт DreamShaper XL Lightning, лицензия
CreativeML OpenRAIL++, разрешает коммерческое использование результатов), фон вещей вырезан rembg (модель
isnet-general-use, Apache-2.0), сжато в WebP. Промпты и отбор — в рабочей папке генератора владельца (вне репозитория).
Картинки — часть проекта под его лицензией.
