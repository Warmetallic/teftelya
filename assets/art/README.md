# Арт тем: картинки фонов

Папка на тему (`fridge`, `kitchen`, `oven`, `sink`, `feast`), в каждой `back.webp` — бесшовный по вертикали задник места
(960 px шириной) и вещи-«герои» с прозрачным фоном (высота до 720 px). Слои, свет, размытие и параллакс собирает
`src/art.js`; список имён на тему — `ART_SRC` там же. Спека: `docs/specs/2026-09-29-v2-2c-art-design.md`.

Откуда картинки: сгенерированы локально владельцем (Stable Diffusion XL, чекпоинт DreamShaper XL Lightning, лицензия
CreativeML OpenRAIL++, разрешает коммерческое использование результатов), фон вещей вырезан rembg (модель
isnet-general-use, Apache-2.0), сжато в WebP. Промпты и отбор — в рабочей папке генератора владельца (вне репозитория).
Картинки — часть проекта под его лицензией.
