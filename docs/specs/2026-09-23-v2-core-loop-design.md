# Тефтеля v2. Петля с риском: прыжок в точку, башни-уровни, серия и берсерк — дизайн

Дата: 2026-09-23. Статус: согласован с владельцем по разделам 1–6, ждёт чтения спеки владельцем и планов v2.1–v2.4.
Заменяет игровую петлю этапов 1–3a. Остаются: SDK Яндекса, сохранения (с миграцией), языки, звук, тестовый стенд,
сборка (`docs/specs/2026-09-10-foundation-sdk-design.md`). Спека этапа 3 (`2026-09-23-floors-skins-design.md`)
после v2.1 считается исторической: люк, этажи по 150 м и старт с любого этажа удаляются.

## 1. Почему v2 и цели

Вердикт владельца после игры в сборку 3a (2026-09-23): вся прокачка за 1–2 минуты; с магнитом и зарядами играть
можно не глядя; масса на весь экран выглядит странно; люк по массе бесит, а масса нигде не видна; этажи по 150 м
проходятся без ощущения завершения; магазин похож на менюшку; Тефа выглядит как куча кала. Итог: в игре нет риска,
а значит нет игры.

Цели v2:
1. Каждый прыжок — решение. Промах наказывается сразу и понятно.
2. Есть что терять и есть чем рисковать: масса как здоровье, опасности, которые убивают.
3. Уровни с финишем, оценкой и бесконечным продолжением: башня за башней.
4. Прокачка Тефы актуальна и через 5 минут, и через 5 месяцев: башни растут вместе с ней.
5. Тефа выглядит как еда.

Вне рамок v2.1–v2.3: звук и графика окружения как отдельный проход (v2.4), лидерборды, покупки за деньги,
вертикальные полосы 19.5:9, экономика по метрикам (отдельный проход после v2.1).

## 2. Решения владельца (2026-09-23)

| Вопрос | Решение | Почему |
|---|---|---|
| Управление | Платформы + прыжок в точку (тап задаёт точку прилёта), 3 заряда в воздухе | Максимум решений на один тап, работает на телефоне |
| Урон | Масса как здоровье: удар отрывает кусок; лопасти и падение убивают сразу | Наказание мгновенное, но не сразу на старт |
| Берсерк | Награда за отличную игру (серия), а не за обжорство | Награда должна быть заслужена, а не куплена |
| Мухи | Наводящиеся преследователи для сильных игроков и наказание ленивых (сидение на платформе); можно увернуться, со временем отстают, в берсерке съедаются | Угроза растёт вместе с успехом, берсерк превращает её в еду |
| Сковородка | Горячая платформа: через ~2 с ожог, если не ушёл | Платформа с налогом, а не убежище |
| Башни | Конечные уровни, число башен бесконечно; выбора нет: одна текущая башня, прошёл — открылась следующая | Ощущение завершения плюс бесконечный прогресс |
| Магазин | Постоянная прокачка Тефы без потолка; новые башни проходимы только прокачанной Тефой | Магазин актуален на любом сроке игры |
| Графика Тефы | Из листа 1 годится только D (прессованная форма); фактуру и цвет брать с фотографий жареных тефтелей и фарша | Остальные варианты похожи на картошку |
| Отвергнуто | Тёмная кладовка (видимость кругом) | Трудно сделать хорошо, на телефоне раздражает |

## 3. Ядро: прыжок, платформы, опасности

Координаты: канвас 480×854 (портрет), мир скроллится вверх, `y` растёт вниз. Все числа черновые и живут в одном
месте (`src/tower.js` для генерации, `src/game.js` для физики прыжка), в коде не дублируются.

### 3.1 Прыжок в точку
- Тап в точку `(tx, ty)` мира. Высота дуги `dy = clamp(ball.y − ty, JUMP_MIN_H, JUMP_MAX_H)` (черновик 100 и 250 px);
  `vy = −sqrt(2·G·dy)`, `t = −vy / G`, `vx = clamp((tx − ball.x) / t, −VX_MAX, VX_MAX)` (черновик `VX_MAX = 420`).
  Тап ниже Тефы — короткий прыжок (`JUMP_MIN_H`) в сторону `tx`. Вершина дуги приходится на точку тапа: игрок
  целится туда, где хочет оказаться.
- Заряды: на платформе `CHARGES = 3` (+ ветка «Заряд»). Каждый тап в воздухе тратит заряд; при нуле тап
  игнорируется с коротким звуком. Приземление на любую платформу возвращает все заряды. Заряды рисуются точками у Тефы.
- Стены отталкивают без урона (`vx` меняет знак с затуханием 0.6). Удар о стену больше не отрывает мясо.
- Камера едет только вверх: `camY = min(camY, ball.y − H·0.6)`. Если `ball.y − ball.r > camY + H + 40` — смерть «упало».
- Клавиатура (десктоп): стрелки/AD задают точку на расстоянии `VX_MAX·t` в сторону, W/пробел/вверх — прыжок вверх.

### 3.2 Платформы башни 1
| Тип | Поведение |
|---|---|
| Тарелка | Безопасна. Ширина 120–180 px. |
| Сковородка | Горячая. Таймер `PAN_TIME = 2 с` (+ «Корочка», − жар башни, не меньше 0.5 с): шипение, дымок, Тефа темнеет; по истечении — урон `dmg(N)`, автопрыжок вверх, таймер сброшен. Заряды восстанавливает. |
| Поднос | Едет по горизонтали между границами ряда, 60–120 px/с; Тефа едет вместе с ним. |

Приземление: сверху (`vy > 0`), нижняя точка Тефы в полосе `[top − 6, top + 18]` и по `x` внутри ширины —
Тефа ставится на верх, `vy = 0`, заряды восстановлены, `squash`. Платформы с новым `id` дают +1 к серии (см. §4).
Снизу и сбоку платформы проницаемы (как в Doodle Jump).

Бэклог платформ (с v2.2, по одной на башню): лопатка-батут (подброс выше `JUMP_MAX_H`), тостер (через 1 с выстреливает
вверх, нужен тайминг), разделочная доска с ножом (рубит с замахом, стоять можно между ударами), полка холодильника
(скользкая, Тефа съезжает к краю), ломтик сыра (крошится через 0.5 с после приземления), миска (липкая, выпрыгнуть
можно только с двух зарядов).

### 3.3 Опасности башни 1
Урон одного касания `dmg(N) = 1 + floor((N − 1) / 8)` кусков массы; после урона 1 с неуязвимости и отброс.

| Опасность | Поведение |
|---|---|
| Муха | Наводящаяся. Появляется по правилам §4.3. Предупреждение 0.7 с: жужжание и стрелка у края экрана. Летит к Тефе со скоростью `FLY_SPEED(N) = 220 + 5N` px/с (всегда медленнее прыжка) с синусоидальным вилянием. Отстаёт через `FLY_CHASE = 6 с` (− «Репеллент», не меньше 1.5 с) и улетает: +3 к серии. Укус: урон, серия по «Стойкости», муха улетает. Одновременно не больше 3, интервал между влётами не меньше 2 с. В берсерке касание = Тефа съедает муху: +монеты, +1 масса. |
| Капли масла | Половник над отмеченным `x` ряда капает каждые `OIL_T = 2.2 с`, капля падает 420 px/с, на платформе оставляет шипящую кляксу на 0.5 с. Касание: урон. |
| Нож на пружине | Ходит поперёк разрыва между платформами: замах 0.6 с (виден), удар 0.3 с, пауза 1.2 с. Касание в фазе удара: урон и отброс. |
| Лопасти миксера | Вращаются в фиксированной точке. Касание — смерть при любой массе. Редкие: с башни 3, не больше одной на 15 рядов. |

В берсерке (§4.4) Тефа сносит мух, капли и ножи (они исчезают, +монеты); лопасти в берсерке останавливаются и
разлетаются (награда за берсерк). Единственная смерть в берсерке — падение за экран.

Старый мусор (волосы, грязь, муха-предмет) удаляется: это были слабые версии опасностей.

Бэклог опасностей (с v2.2): скалка (катится вдоль ряда), струя пара (зона по таймеру, отталкивает и жжёт), вилка
(статичные зубцы), перчик (взрыв при касании, отброс и ожог, рядом всегда еда), кошачья лапа (сметает ряд с большим
замахом).

### 3.4 Подборы (временные, не продаются)
Пакетик соуса: щит на один удар до конца башни. Петрушка: +1 заряд на 10 с. Кубик льда и золотая тефтелька — бэклог.

### 3.5 Еда
Кетчуп, макароны, мясо остаются как предметы: монеты (базовые 1/2/3 × «Специи» × множитель башни) и +1 кусок массы до
максимума. Магнит на еду в обычном режиме отсутствует принципиально: прицеливание в еду — часть решения.

## 4. Масса, серия, мухи, берсерк

### 4.1 Масса как здоровье
- `MASS_MAX = 4 + up.meat`, старт башни с `MASS_MAX − 1`. Удар отнимает `dmg(N)` кусков с брызгами и отбросом.
  Ноль кусков, падение за экран или лопасти — «Шлёп!».
- Тефа растёт с массой в узком диапазоне: радиус `26 + 4·(mass − 1)`, не больше `26 + 4·7`. Никакого шара на весь экран.
- HUD: ряд иконок-тефтелек по числу `MASS_MAX` (при `MASS_MAX > 8` — число), потерянные гаснут; при ударе кусок
  улетает частицей.
- Еда лечит на 1 кусок. При полной массе еда даёт только монеты и серию.

### 4.2 Серия
- События: съел еду +1; приземлился на платформу с новым `id` +1; муха отстала +3. Серия видна в HUD полосой с числом.
- Урон отнимает долю серии по ветке «Стойкость»: 100% (база), 50%, 25%.
- Порог берсерка `BERSERK_AT = 12` (ветка «Кураж»: 10, 8).

### 4.3 Мухи: когда прилетают
- Серия высокая: при `streak ≥ 6` шанс влёта в секунду `0.08 + 0.02·(streak − 6)`, не больше 0.4.
- Лень: Тефа стоит на одной платформе `CAMP_T = 3 с` — муха влетает гарантированно.
- Ограничения: не больше 3 одновременно, интервал не меньше 2 с, в берсерке новые не влетают.
- Обоснование в игре: Тефа в ударе вкусно пахнет.

### 4.4 Берсерк
- Включается при `streak ≥ BERSERK_AT`. Длительность `BERSERK_T = 6 с` (+0.5 с за уровень «Аппетита»).
- Тефа раздувается до радиуса ×1.6, неуязвима, сносит опасности (§3.3), не горит на сковородках, магнит радиусом
  140 px на еду и монеты, монеты ×2, тряска камеры и другой звук. Мух съедает.
- После берсерка серия = 0, масса не меняется. Падение за экран убивает и в берсерке.

## 5. Башни: бесконечные уровни, рейтинг, летопись

### 5.1 Башня N
- Башня генерируется детерминированно по сиду N (`mulberry32(N)`): раскладка одинакова при каждом заходе, её можно
  выучить. Случайны только тайминги мух.
- Ряды платформ через `ROW_H = 120 px`; число рядов `rows(N) = min(40 + 5N, 160)`. Каждые 20 рядов — отметка этажа
  с чекпоинтом. Верхний ряд — крыша: широкая платформа-финиш.
- Две дорожки: левая и правая половины, в каждом ряду платформа хотя бы в одной; «жадная» дорожка с едой и
  опасностями, «безопасная» длиннее и с меньшим числом еды. Каждые 2–3 ряда дорожки сходятся — выбор пути.
- Проходимость гарантируется генератором: от любой платформы ряда есть платформа следующего ряда в пределах
  `JUMP_MAX_H` по высоте и `VX_MAX·t` по горизонтали; тест проверяет это для сотни башен.
- Параметры роста: плотность опасностей `p(N) = min(0.15 + 0.02N, 0.6)` на ряд; скорость опасностей `×(1 + 0.03N)`;
  урон `dmg(N)`; жар башни `heat(N) = min(0.05N, 1.5) с` вычитается из таймера сковородок; доля сковородок среди
  платформ `min(0.1 + 0.02N, 0.5)`; еды на ряд `max(0.35, 0.8 − 0.01N)`. Пороги: подносы и ножи с башни 2, лопасти
  с башни 3; бэклог платформ и опасностей включается по одному типу на башню начиная с v2.2.
- Темы циклом по 5 башен: кухня, холодильник, духовка, раковина, праздничный стол. В v2.1 только кухня; правила тем
  (скользко, жар снизу, вода прибывает, тучи мух и горы еды) — v2.2, там же их спека.
- «Сила Тефы» = взвешенная сумма уровней прокачки; у башни есть рекомендуемая сила `power(N)` (формула — в плане
  v2.3 по метрикам). Замка нет: зайти можно слабее, но урон `dmg(N)` и жар делают башню непроходимой без прокачки.
  Монеты за частичный забег остаются у игрока, поэтому застрявший игрок копит на прокачку в той же башне.

### 5.2 Смерть, чекпоинт, продолжение
- Смерть: «Шлёп!» и причина одной строкой без гендерных форм («Муха укусила», «Упало в пропасть», «Лопасти»,
  «Сгорело на сковородке», «Масло», «Нож»).
- «Продолжить» за rewarded: с места смерти, масса `max(2, …)`, 1.5 с неуязвимости; один раз на башню; рейтинг
  башни становится D.
- «С чекпоинта» бесплатно: старт с последней отметки этажа, `deaths += 1`, монеты забега сохраняются.
- «Заново»: башня с нуля, `deaths = 0`, время с нуля.
- Монеты, заработанные в забеге, банкуются при смерти и при финише (`bankedCoins` как в 3a).

### 5.3 Финиш и рейтинг
- Приземление на крышу — башня пройдена. Экран финиша: буква рейтинга с ударом, под ней три проверки галочками:
  без смертей; время не больше нормы `par(N) = rows(N)·2.4 с`; еды собрано не меньше 80% от еды башни.
  Три галочки S, две A, одна B, ноль C; было «Продолжить» — D.
- Награда: монеты башни `20·N × {S: 2, A: 1.5, B: 1.2, C: 1, D: 0.8}`, «Монеты ×2» за rewarded. Скин за первый S
  каждой пятой башни (5, 10, 15, …).
- После финиша `save.tower = N + 1`, в летопись пишется `{r, t}` по башне N (лучшее сохраняется при повторе — повтора
  нет, но слияние с облаком его допускает).

### 5.4 Титул и летопись
- Титул: крупно «Башня N», тема, рекомендуемая сила и сила Тефы, кнопка «Играть»; Тефа на тарелке. Ниже прокручиваемая
  летопись пройденных башен: номер, буква рейтинга, время. Тап по летописи ничего не запускает. Кнопки: магазин, язык.
- Селектор этажей и старый титул удаляются.

## 6. Магазин и прокачка (v2.3)

Принципы: прокачка делает Тефу крепче, башни растут вместе с ней; ни один апгрейд не отбирает решение у игрока
(нет автоприцела, нет магнита на еду вне берсерка); лестница без конца для веток-чисел.

| Ветка | Эффект за уровень | Потолок |
|---|---|---|
| Мясистость | +1 к `MASS_MAX` | нет |
| Корочка | +0.25 с к таймеру сковородки | нет |
| Аппетит | +0.5 с берсерка | нет |
| Специи | +5% монет за еду | нет |
| Кураж | порог берсерка 12 → 10 → 8 | 2 |
| Стойкость | урон отнимает 100% → 50% → 25% серии | 2 |
| Репеллент | −0.3 с к погоне мухи, не меньше 1.5 с | 15 |
| Заряд | +1 заряд прыжка; уровни открываются после башен 3, 10, 25 | 3 |

- Цена уровня `L`: `base · 1.3^L` (базы по веткам — в плане v2.3 по метрикам дохода после v2.1). Доход растёт с
  номером башни (награда `20·N`, множитель монет за еду `1 + 0.05N`), поэтому темп покупок одинаков у новичка и у
  игрока на пятом месяце.
- Рейтинг S доступен с любой прокачкой; расходников в магазине нет (подборы только в башне).
- Экран: Тефа крупно в центре, реагирует на прокачку (мясистость — больше, корочка — темнее, аппетит — свечение);
  сетка веток с уровнем, эффектом и ценой; вкладки «Прокачка» и «Скины»; «Сила Тефы» вверху.
- Скины: часть за монеты, часть только за S (не покупаются). Список и эффекты — в плане v2.3, рисует та же функция
  `drawTefa`, что и в игре.

## 7. Экраны, HUD, тексты

- HUD: иконки массы слева сверху, под ними полоса серии с числом, точки зарядов у Тефы, монеты справа, тонкая
  вертикальная полоса прогресса башни с отметками этажей справа. Метров нет.
- Предупреждение о мухе: стрелка у края и жужжание 0.7 с до влёта.
- Пауза, ориентация, звук, десктопная раскладка — как в этапе 1.
- Тексты ru/en/tr, `T(key, n)`; в русских строках о Тефе без гендерных форм: «Шлёп!», «Упало в пропасть», «Сгорело».
  Новые ключи: башня, играть, сила, серия, берсерк, рейтинг и три проверки, причины смерти, с чекпоинта, заново,
  следующая башня, летопись, названия и описания веток прокачки, названия тем.

## 8. Сохранение v4 и слияние

```
{ v: 4, earned, spent,
  up: { meat, crust, appetite, spice, nerve, grit, repel, charge },
  skins: [], skin: 'none',
  tower: 1,                 // текущая башня (≥ 1)
  log: { "1": { r: 'S', t: 123.4 } },   // пройденные башни
  cp: 0 }                   // индекс чекпоинта в текущей башне (0 — нет)
```
- Миграция: v1–v3 → `earned` остаётся, `spent = 0` (старые апгрейды возвращаются монетами), `up` нули, `skin`
  остаётся, если есть в новом списке, `tower = 1`, `log = {}`, `cp = 0`; `best`, `floor`, `startFloor` забываются.
- Слияние с облаком: `earned`/`spent` максимум (реестр монотонный, `coins = max(0, earned − spent)`); `up` по веткам
  максимум; `skins` объединение; `skin` — больший индекс; `tower` максимум; `log` по башне — лучший рейтинг
  (S > A > B > C > D), при равном — меньшее время; `cp` — из сохранения с большей `tower`, при равной — максимум.

## 9. SDK Яндекса и реклама
Как в этапе 1: `gameplayStart/Stop` на каждый забег (старт башни, смерть, финиш, пауза), межстраничная после экрана
смерти/финиша не чаще `AD_INTERVAL = 180 с` и не на первом экране сессии, rewarded на «Продолжить» и «Монеты ×2».
Лидерборд — бэклог (бесконечный режим).

## 10. Графика Тефы
- Процесс: лист вариантов рендерится `tools/design_tefa.js` (node-canvas) в `shots/design_tefa_*.png`, владелец
  утверждает вариант. Лист 1 отвергнут кроме D. Лист 2 строится от формы D по фотографиям жареных тефтелей и
  фарша: поверхность из зёрен фарша (много мелких пересекающихся гранул 3–4 тонов, край бугристый от самих зёрен),
  палитра тёмно-красно-коричневая с почти чёрными подпалинами и карамельными бликами на зёрнах, мокрый жирный блеск,
  крапинки орегано; форма прессованная, слегка приплюснутая, без идеального круга; мультяшное лицо на более гладкой
  передней зоне. На 52 px зерно должно читаться как фактура, а не шум (уровень детализации по радиусу).
- Утверждённый вариант становится `src/tefa.js`: `drawTefa(ctx, x, y, r, variant, skin, pose)`; деформация тела
  (сквош, отскок) — трансформацией, а не по точкам; скины — слои поверх. Старая отрисовка тела удаляется в v2.1.

## 11. Архитектура

Порядок скриптов: `core, i18n, audio, sdk, save, ball, tefa, tower, platforms, hazards, streak, game, render, screens, main`.
Зависимости только вниз; модули ниже `game` возвращают события и не пишут его состояние.

| Модуль | Ответственность |
|---|---|
| `ball.js` | физика тела: позиция, скорость, масса, радиус, сквош; без отрисовки |
| `tefa.js` (новый) | отрисовка Тефы по утверждённому дизайну, скины, берсерк-вид |
| `tower.js` (новый) | сиды, `rows(N)`, `p(N)`, `dmg(N)`, `heat(N)`, `par(N)`, генерация рядов: платформы, опасности, еда, чекпоинты, крыша; гарантия проходимости |
| `platforms.js` (новый) | типы платформ, обновление (поднос, таймер сковородки), посадка, события `land`/`burn` |
| `hazards.js` (новый) | муха, масло, нож, лопасти: обновление, столкновения, события `hit`/`kill`/`flyGaveUp`/`eaten` |
| `streak.js` (новый) | серия, порог, берсерк: чистое состояние и события `berserkStart/End` |
| `game.js` | оркестрация: прицел прыжка, заряды, камера, применение событий, урон, смерть, чекпоинты, финиш и рейтинг, монеты |
| `render.js` | мир и HUD |
| `screens.js` | титул с летописью, смерть, финиш, магазин (v2.3) |
| `main.js` | ввод (тап/клавиатура), boot/restart, SDK-связка |
| удаляются | `world.js`, `floors.js`, `upgrades.js` |
