# Этап 3. Этажи башни, люк, скины и реплики Тефы — дизайн

Дата: 2026-09-23. Статус: согласован с владельцем по секциям, ждёт планов реализации (3a, 3b).
Опирается на этапы 1–2 (`docs/specs/2026-09-10-foundation-sdk-design.md`, `docs/specs/2026-09-23-meta-shop-design.md`).

## 1. Цель и рамки

Дать забегу структуру и цель на 20 секунд вперёд: башня делится на этажи, у потолка каждого — люк, который
пробивает только достаточно раскормленная тефтеля. Пройденный этаж открывается для старта, за первый и каждый пятый
этаж — скин с лёгким эффектом. Персонаж получает имя (Тефа) и реплики. Сессия удлиняется: игрок стартует с фронта
своего прогресса, а не повторяет лёгкое начало.

Вне рамок: графика и звук как таковые (отдельные проходы позже), лидерборд, покупки за деньги, вертикальные полосы на
высоких телефонах, метрики экономики.

## 2. Решения владельца (2026-09-23)

| Вопрос | Решение | Почему |
|---|---|---|
| Башня | Бесконечная; этажи открываются; старт с любого открытого со стартовой массой этажа | Видимый прогресс и короткие цели без повтора лёгких этажей |
| Испытание | Люк по массе с гарантированным буфетом; без массы — вентиляция без награды | Собрано из существующих систем: масса, еда, множитель |
| Косметика | За 1-й этаж, затем каждые 5 (агент выбрал 5 из «5 или 10»); скины с лёгким эффектом | Награда за каждый этаж обесценивается; эффект даёт выбор перед забегом |
| Имя | Тефа (Tefa), без рода | Коротко, тепло, читается латиницей; в русских текстах никаких гендерных форм |
| Подход | Этажи как разметка высоты по 150 м | Гейты, доля мусора, отметки и рекорд работают без правок |
| Разбиение | Одна спецификация, два плана и две ветки: 3a этажи/люк/сохранения/экраны, 3b скины/реплики | 3b зависит от 3a через открытие этажей |

## 3. Этажи и старт

- `FLOOR_H = 150` м (1500 px). Этаж N занимает высоты `[150·(N−1), 150·N)`; `floorOf(h) = floor(h / 150) + 1`; потолок этажа N на высоте `150·N` (мировой `y = −1500·N`).
- `startMass(N) = N === 1 ? 1 : min(1 + N, 12)`; `hatchMass(N) = min(3 + N, 15)`; `hatchBonus(N) = 5 + 5·N` монет (черновые числа, живут в `src/floors.js`).
- Старт с этажа N (`reset(N)`): `baseY = −1500·(N−1)`; тарелка `{x: W/2, y: baseY + 30, w: 220}`; тефтеля на `baseY` с массой `startMass(N)` и полными зарядами; `camY = baseY − H + 120`; `spawnedTo = baseY − 160`; `maxHeight = 150·(N−1)` сразу при старте и дальше считает абсолютную высоту, `save.best` — абсолютный рекорд. `reset(N)` заменяет `reset()`; `restart()` и загрузка передают `save.startFloor`.
- Выбранный этаж хранится в `save.startFloor` (1 … `save.floor + 1`) и выбирается на титуле (§7). `save.floor` — максимальный честно пройденный этаж (0 в начале).
- Сложность по абсолютной высоте не меняется (`TRASH_FROM`, `trashP`, отметки метров).

## 4. Люк, буфет, вентиляция

- **Сущность люка** создаётся спавном, когда `spawnedTo` проходит потолок этажа N: `hatch = { floor: N, y: −1500·N, need: hatchMass(N), broken: false, vented: false, underT: 0 }`. Люки хранятся списком `hatches[]`; столкновение и таймер вентиляции считаются для ближайшего не открытого люка над тефтелей; после пробития или вентиляции люк остаётся в мире как «открытый» до ухода за нижний край и удаляется вместе с предметами.
- **Столкновение** (`updateRun`): если люк не открыт, тефтеля ниже него (`ball.y > hatch.y`), летит вверх (`vy < 0`) и `ball.y − ball.r ≤ hatch.y + 12`:
  - `ball.mass ≥ hatch.need` → **пробитие**: `hatch.broken = true`, `burst` фаршем и щепками, `camShake = 12`, `sfx.big`, `runCoins += hatchBonus(N)` (с всплывающим `+N`), надпись `T('floorCleared', N)`; если `N > save.floor` → `save.floor = N`, `persist()`, флаг `newUnlock = N + 1`; скин по §5, если положен.
  - иначе → **отскок**: `ball.y = hatch.y + 12 + ball.r`, `ball.vy = 200`, `squash`, `sfx.hit` (масса не теряется), надпись `T('needMass', need)`; не чаще раза в 0.5 с.
- **Буфет**: в последних 20 м этажа (`h mod 150 > 130`) обычный `spawn()` рядов не генерирует; при создании люка кладутся `meat` на `(160, hatch.y + 120)` и `pasta` на `(320, hatch.y + 60)` (+3 массы). Скин «колпак» добавляет `ketchup` на `(240, hatch.y + 90)`.
- **Вентиляция**: пока люк не открыт и тефтеля в 30 м под ним (`hatch.y < ball.y ≤ hatch.y + 300`), копится `hatch.underT += dt`; при `underT ≥ VENT_TIME = 8` → `hatch.vented = true`, звук `tone(300, 500, 0.3)`, надпись `T('vented')`. Открытый вентиляцией люк пропускает, но этаж не засчитывается: ни бонуса, ни скина, ни `save.floor`.
- **Рисование**: полоса во всю ширину толщиной 24 px цвета `#6d5a48` с заклёпками, по центру табличка `T('massAtLeast', need)`; пробитый — рваный край и обломки; вентилируемый — полоса отъехала к правому краю, проём слева (визуально), проходимость полная.
- **Отслеживание забега**: `floorReached = max(floorOf(-ball.y/10))`, `clearedThisRun[]`, `newUnlock`, `newSkin` — для экрана результатов.

## 5. Скины (3b)

Только надетый скин действует. Каталог `SKINS` в `src/skins.js`:

| id | Этаж | Вид | Эффект |
|---|---|---|---|
| `chef` | 1 | белый колпак повара над петрушкой | буфет +1 кетчуп |
| `glasses` | 5 | круглые очки на глазах | волосы безвредны с массы 5 (`hairProofMass() = 5`) |
| `crown` | 10 | золотая корона | +1 монета за каждое мясо сверх множителя |
| `bow` | 15 | красный бантик сбоку | неуязвимость после «Продолжить» 2.5 с |
| `mustache` | 20 | усы под глазами | первый удар о стену за забег не отрывает мясо |

- Открыт, если `save.floor ≥ SKINS[i].floor`. `save.skin` ∈ `'none' | id`. При первом прохождении этажа со скином скин сразу надевается, на результатах строка `T('newSkin', name)`.
- Выбор: на титуле тап по тефтеле (в радиусе `ball.r + 24` от её центра) перебирает `['none', …открытые]` по кругу, `persist()`; подпись под тефтелей: `T('thisIsTefa')` и ниже имя скина с эффектом (`T('skin.<id>') + ': ' + T('skin.<id>.effect')`), для `none` — только `T('thisIsTefa')`.
- Эффекты подключаются через функции в `skins.js`: `hairProofMass()`, `meatBonus()`, `invulnTime()`, `wallGrace()`, `buffetExtra()`; `game.js` и `floors.js` читают их вместо констант `HAIR_PROOF`, `INVULN_TIME` и прямых значений.
- Рисование: `drawSkin(ctx, ball)` вызывается из `drawBall()` после лица; фигуры масштабируются от `ball.r`, следуют за верхней точкой тела как петрушка.

## 6. Реплики Тефы и тексты без рода (3b)

- Пузырь над тефтелей: скруглённый прямоугольник с хвостиком, ширина по `measureText`, шрифт 18 px, живёт `BUBBLE_TIME = 1.2` с, последние 0.3 с гаснет. В забеге не чаще одного раза в `BUBBLE_GAP = 3` с; события `hatchBreak`, `vented`, `die`, `continue` — приоритетные, показываются всегда.
- События и русские варианты (по два; en и tr переводит агент, владелец проверяет по скриншотам):
  `start`: «Наверх!», «Поехали!» · `meat`: «Ммм!», «Вкуснотища!» · `trash`: «Фу!», «Бе-е!» · `hatchBreak`: «Хрясь!», «Этаж мой!» ·
  `hatchBounce`: «Тяжелее надо…», «Ещё поесть!» · `vented`: «Ну ладно…» · `die`: «Ой…», «Шлёп!» · `continue`: «Я снова тут!», «Ещё разок!»
- **Без рода**: во всех русских строках игры нет глаголов прошедшего времени и причастий, относящихся к Тефе. Заголовок результатов `fell` меняется: «Упала» → «Шлёп!» (en «Splat!», tr «Pat!»). README и карточка игры — тем же правилом.
- Титул: под тефтелей `T('thisIsTefa')` = «Это Тефа» / «This is Tefa» / «Bu Tefa».

## 7. Экраны

- **Титул** (сверху вниз): заголовок `H·0.34`, пять подсказок до `≈460` px, селектор этажа на `H·0.57` (кнопки `floor-` и `floor+` 44×44 по бокам от текста `T('floor') + ' ' + startFloor`, показывается только при `save.floor ≥ 1`), кнопка `shop` на `H·0.64`, `tapToJump` на `H·0.75`, тефтеля на тарелке (`y ≈ 764`), подписи на `808` и `830` px. Тап вне кнопок и вне тефтели — старт с `startFloor`.
- **HUD**: под метрами строка `T('floor') + ' ' + floorOf(h)` (600 15px, alpha 0.7).
- **Результаты**: строки после «Собрано за забег» и «Всего»: `T('floor') + ' ' + floorReached`; при `newUnlock` — `T('floorUnlocked', newUnlock)`; при `newSkin` — `T('newSkin', name)`. Шаг 30 px, до шести строк, кнопки остаются на `H·0.56`.
- **Мир**: люк с табличкой, буфет, пузырь реплики (3b), скин на тефтеле (3b).

## 8. Сохранения v3

`{ v: 3, best, earned, spent, up: {jumps, magnet}, floor, startFloor, skin }`.
- `migrate`: v2 → `floor = 0, startFloor = 1, skin = 'none'`; `floor` целое ≥ 0; `startFloor` зажимается в `[1, floor + 1]`; `skin` ∈ `SKIN_ORDER = ['none', 'chef', 'glasses', 'crown', 'bow', 'mustache']`, иначе `'none'`.
- `mergeSaves`: `floor` и `startFloor` — максимум (затем зажим `startFloor ≤ floor + 1`); `skin` — больший индекс в `SKIN_ORDER`; остальное как v2. Обоснование: все поля монотонны или упорядочены, игрок никогда не теряет.
- `persist()` дополнительно при пробитии люка с новым рекордом этажа, при смене скина и при смене стартового этажа.

Правило зависимостей: `save → upgrades → ball → world → floors → skins → lines → game → render → screens → main`.
`floors.js` читает `ball`/`world`, а `world.js` не знает про этажи: подавление спавна в зоне буфета идёт через хук `spawnFilter`, который `floors.js` выставляет при загрузке; люки создаёт `spawnHatches()` из `game.js` после `spawn()`. `hatchUpdate(dt)` возвращает событие (`break` / `bounce` / `vent`), а тряску, бонус монет и прогресс применяет `game.js`.

## 13. Открытые вопросы (не блокируют)

- Числа `hatchMass`, `startMass`, `hatchBonus`, `VENT_TIME` — черновые, настроить по ощущениям и метрикам.
- Вентиляция не открывает этаж: если игроки массово застревают, разрешить открытие с пометкой «не по-честному» или снизить `hatchMass`.
- Название игры «Тефтеля» остаётся; имя Тефа только у персонажа. Пересмотреть на этапе релиза при подготовке карточки.
