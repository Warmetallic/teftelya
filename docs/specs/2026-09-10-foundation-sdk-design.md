# Этап 1. Фундамент и Yandex Games SDK — дизайн

Дата: 2026-09-10. Статус: согласован с владельцем (геймдизайнером), ждёт плана реализации.

## 1. Цель и рамки

Превратить одностраничный прототип `teftelya.html` в проект, который:
- собирается в один `dist/index.html` и `dist/teftelya.zip`, пригодный для загрузки в консоль Яндекс Игр;
- выполняет все обязательные требования модерации по SDK (готовность загрузки, старт/стоп геймплея, пауза, звук при потере фокуса, реклама только через SDK);
- монетизируется: межстраничная реклама между забегами, rewarded «Продолжить» и «Монеты ×2»;
- хранит прогресс в облаке Яндекса с резервом в localStorage;
- говорит на русском и английском;
- корректно выглядит на десктопе и при повороте телефона;
- разбит на модули, чтобы следующие этапы (мета, этажи) не превращали код в один файл на 2000 строк.

Механика забега (прыжки, еда, мусор, масса, стены) на этом этапе **не меняется**. Единственное игровое дополнение — «Продолжить» после падения.

Вне рамок этапа: магазин апгрейдов, этажи башни, имя и реплики тефтели, ассеты карточки игры, загрузка в консоль. Это этапы 2–5.

## 2. Требования Яндекс Игр (проверены по документации 2026-09-10)

| Требование | Как выполняем |
|---|---|
| В корне архива `index.html`, имена файлов латиницей без пробелов, до 100 МБ | `tools/build.js` собирает `dist/index.html` и `dist/teftelya.zip` с одним файлом внутри |
| SDK подключён и инициализирован по документации | тег `<script src="/sdk.js">` в `index.html`; `YaGames.init()` в `sdk.js` |
| `ysdk.features.LoadingAPI.ready()` когда игра готова к взаимодействию | вызывается один раз, когда отрисован титул |
| `GameplayAPI.start()` / `stop()` в нужные моменты; после `stop()` игра реально стоит | start: первый тап на титуле, тап «продолжить» после паузы, возврат после рекламы; stop: смерть, показ рекламы, пауза |
| Подписка на `game_api_pause` / `game_api_resume` через `ysdk.on` | `main.js` подписывается после init; при паузе — стоп цикла и mute |
| Звук стихает при потере фокуса | `audio.mute()` = `AudioContext.suspend()` |
| Межстраничная реклама не во время активной игры; частоту контролирует Яндекс | показываем только по тапу «Ещё раз», плюс свой лимит (см. раздел 6) |
| Данные игрока через SDK, работают и без авторизации, до 200 КБ, ≤100 запросов за 5 минут | `save.js` пишет только при смерти и покупках |
| Язык через `ysdk.environment.i18n.lang`, локализация минимум на один язык | ru + en, остальные → en |
| Десктоп: поле до краёв окна, без полос; при повороте ничего не обрезано | холст на всё окно, поле 480×854 по центру, бока залиты фоном |
| Долгий тап не выделяет текст и не открывает меню | `contextmenu` → `preventDefault`, `user-select:none`, `touch-action:none` (уже есть) |
| Локальный тест в проде: `npx @yandex-games/sdk-dev-proxy -p dist` + draft-URL игры с `?game_url=https://localhost` | делает владелец после создания черновика игры в консоли; до этого работает заглушка SDK |

## 3. Структура проекта

```
teftelya/
  index.html            dev-версия: стили + <script src="src/…"> по порядку из списка ниже
  src/
    core.js  i18n.js  audio.js  sdk.js  save.js  ball.js  world.js  game.js  render.js  screens.js  main.js
  tools/
    _env.js   headless-окружение (читает порядок src из index.html)
    smoke.js  прогон всего потока экранов на заглушке SDK, падает при любой ошибке
    shot.js   скриншоты через node-canvas (npm i canvas)
    build.js  склейка + zip → dist/
  dist/                 артефакт сборки, в .gitignore
  docs/
    DEVLOG.md           журнал разработки
    specs/  plans/      дизайн-документы и планы этапов
  README.md             текущее состояние правды (правила, устройство, как проверять)
  preview.png
```

`teftelya.html` удаляется; его заменяет `index.html`. `tools/_env.js` берёт порядок файлов из `index.html`, чтобы список существовал в одном месте.

Модули — обычные скрипты (не ES-модули). Верхнеуровневые `const`/`let`/`function` одного скрипта видны в следующих, поэтому пространство имён не нужно. `build.js` склеивает файлы в том же порядке внутри одного IIFE со `'use strict'`; дублирование имён между файлами ловится smoke-тестом (SyntaxError при eval).

## 4. Модули: что делает, как используется, от чего зависит

**core.js** — константы `W=480, H=854`, `rnd/clamp/lerp`, объект `view` (масштаб, смещение поля, размеры окна), `resize()`, `toGame(event) → [x, y]` в логических координатах поля. Зависит только от DOM.

**i18n.js** — таблица строк `STR = { ru: {...}, en: {...} }`, `setLang(code)`, `T(key, ...args)`. Ключи: title, hint1..hint5, tapToJump, fell, best, runCoins, total, again, continueAd, doubleAd, paused, tapToContinue, mass, hairProof, meatLost, pf, adStub. Нет зависимостей.

**audio.js** — как сейчас (`audio/tone/sfx`) плюс `mute()` / `unmute()` через `suspend/resume` контекста и флаг `muted`, чтобы `tone()` молчал в паузе. Нет зависимостей.

**sdk.js** — объект `YG` с единым интерфейсом, за которым либо реальный `ysdk`, либо заглушка:
- `YG.init() → Promise<void>`: ждёт появления `window.YaGames` до 3 с (тег `/sdk.js` грузится асинхронно); если есть — `YaGames.init()`; если нет или ошибка — заглушка. Никогда не отклоняется.
- `YG.isMock`, `YG.lang` ('ru' | 'en' | иной код).
- `YG.ready()`, `YG.gameplayStart()`, `YG.gameplayStop()` — с флагом `gameplayActive`, чтобы не слать `start` дважды подряд и не слать `stop` без `start`.
- `YG.showInterstitial() → Promise<{shown: boolean}>`; `YG.showRewarded() → Promise<{rewarded: boolean}>`. Оба сами вызывают `gameplayStop()` перед показом; возобновление геймплея — задача вызывающего. Никогда не отклоняются: любая ошибка → `{shown:false}` / `{rewarded:false}`.
- `YG.onPause(cb)`, `YG.onResume(cb)` — обёртка над `ysdk.on('game_api_pause'|'game_api_resume')`.
- `YG.getData() → Promise<object|null>`, `YG.setData(obj) → Promise<void>` — через `ysdk.getPlayer()` (кэшируется) с `player.getData()/setData(obj, true)`. Ошибки глотаются в `null` / no-op.
- `YG.storage` — `ysdk.getStorage()` если доступен, иначе `localStorage`, иначе объект-пустышка.
- Заглушка: `showInterstitial` показывает через `screens.adStub('interstitial')` оверлей на 1 с и возвращает `{shown:true}`; `showRewarded` — оверлей на 1.5 с и `{rewarded:true}`; `getData` читает из `localStorage['teft_cloud_mock']`, чтобы облако имитировалось отдельно от резерва.

**save.js** — `SAVE_VERSION = 1`, `save = { v, best, coins }` в памяти. `loadSave() → Promise`: читает облако и локальный резерв, берёт **поле-по-полю максимум** (`best`, `coins`), результат кладёт в память и записывает обратно в оба хранилища, если они расходились. `persist()`: пишет в память → localStorage синхронно → облако асинхронно. Вызывается при смерти, при получении награды ×2 и в будущем при покупках. Ключ localStorage: `teft_save` (старые ключи `teft_best`/`teft_coins` читаются один раз для миграции и удаляются). Зависит от `sdk.js`.

**ball.js** — мягкое тело без изменений: `ball`, `radiusFor`, `initBody`, `deform`, `squash`, `pulse`, `jolt`, `updateBody`, `heavy`. Поля `full`, `hiccup` вычищаются (README: безобидный мусор). Зависит от `core.js`.

**world.js** — `FOOD`, `TRASH`, `pick`, `spawn`, а также частицы и тексты: `particles`, `texts`, `burst`, `crumbs`, `popText`, `loseMeat`, `colorOf`. Зависит от `core.js`, `ball.js`.

**game.js** — состояние забега: `camY`, `items`, `plates`, `maxHeight`, `runCoins`, `tGame`, `usedContinue`, `usedDouble`, `invuln`; функции `reset()`, `eat()`, `wallHit()`, `die()`, `continueRun()`, `updateRun(dt)`, `jump(dir)`. `die()` сам вызывает `persist()` и `YG.gameplayStop()` — `save.js` и `sdk.js` стоят выше `game.js`, правило зависимостей не нарушено. Зависит от `ball.js`, `world.js`, `audio.js`, `save.js`, `sdk.js`.

**render.js** — `drawBg` (с заливкой боков за пределами поля), `drawItem`, `chunk`, `drawBall`, `drawHUD`, `drawWorld()`. Только рисование, состояние не меняет. Зависит от `game.js`, `world.js`, `ball.js`.

**screens.js** — панели и кнопки: `Button {x,y,w,h,label,enabled,onTap}`, `drawPanel`, `titleScreen()`, `resultsScreen()`, `pausedScreen()`, `adStub(kind)`; `hitTest(x, y)` возвращает кнопку под тапом. Все тексты через `T()`. Зависит от `i18n.js`, `core.js`, `game.js` (только чтение чисел).

**main.js** — точка входа: `boot()` (init SDK → загрузить сохранение → выбрать язык → `state='title'` → `YG.ready()`), машина состояний, обработчики ввода, паузы, цикл `frame()`. Зависит от всех.

Правило зависимостей: стрелки только вниз по списку в `index.html`. Модуль не вызывает функции модулей ниже себя; если очень надо — через колбэк, который выставляет `main.js` (как `onDie`).

## 5. Машина состояний

```
title ──тап──▶ play ──смерть──▶ dead(results)
  ▲                               │  │  │
  │            ┌──────────────────┘  │  └──── «Ещё раз» ──▶ [interstitial?] ──▶ play (reset)
  │            │ «Продолжить» ──▶ [rewarded] ──┬─ rewarded ──▶ play (continueRun)
  │            │                               └─ нет ──────▶ dead (кнопка гаснет)
  │            └ «Монеты ×2» ──▶ [rewarded] ──┬─ rewarded ──▶ dead (runCoins×2, кнопка гаснет)
  │                                           └─ нет ──────▶ dead
  └─── (нет пути обратно на титул; титул только при старте)

любое состояние ──пауза──▶ paused(prev) ──резюм──▶ prev (для play — через оверлей «Тапни, чтобы продолжить»)
```

Вызовы SDK по переходам:
- `title` отрисован → `YG.ready()` (один раз за жизнь страницы).
- `title → play`, `paused → play` (по тапу), после рекламы, если следующее состояние `play` → `gameplayStart()`.
- `play → dead`, показ любой рекламы, `→ paused` → `gameplayStop()`.

Во время показа рекламы (промис не завершён) ввод игнорируется, цикл продолжает рисовать последний кадр без `update`, флаг `adBusy = true`.

## 6. Реклама: правила

- **Межстраничная** только по тапу «Ещё раз» на экране результатов. Не показывается: на первом рестарте в сессии; если с прошлого успешного показа любой рекламы (в том числе rewarded) прошло меньше `AD_INTERVAL = 180` с. Заглушка подчиняется тем же правилам и показывает оверлей, чтобы поток проверялся без консоли Яндекса. Результат `{shown:false}` не считается показом и не сдвигает таймер.
- **Rewarded «Продолжить»**: кнопка видна, если `!usedContinue`. Тап → `showRewarded()`; при `rewarded:true` → `continueRun()`, `usedContinue = true`; иначе кнопка остаётся.
- **Rewarded «Монеты ×2»**: кнопка видна, если `!usedDouble && runCoins >= 10`. При награде `coins += runCoins; runCoins *= 2; usedDouble = true; persist()`. Экран результатов сразу показывает удвоенное число с всплывающим текстом «×2».
- Кнопки за рекламу помечены иконкой ▶ и подписью «за рекламу», чтобы игрок не путал их с обычными (требование честности рекламы).
- Ошибка/отмена рекламы никогда не ломает поток: игрок возвращается на тот же экран.

## 7. Продолжить (continueRun)

Согласовано с дизайнером: тарелка внизу, масса не меньше 3.
- Новая тарелка `{x: W/2, y: camY + H - 90, w: 220}` добавляется в `plates`.
- `ball.x = W/2, ball.y = plate.y - ball.r, vx = vy = 0, mass = max(massAtDeath, 3), r = radiusFor(mass), jumps = MAXJ, alive = true`, тело переинициализируется.
- `invuln = 1.5` с: столкновения с мусором и удары о стены не отнимают массу, тефтеля мигает прозрачностью.
- Предметы на экране в радиусе 120 от точки появления удаляются, чтобы не умереть в момент возрождения.
- `maxHeight`, `runCoins`, `camY` сохраняются. `usedContinue = true`.
- `massAtDeath` запоминается в `die()` до обнуления.

## 8. Пауза

Источники: `YG.onPause`, `document.visibilitychange` (hidden), `window.blur`. Возобновление: `YG.onResume`, `visibilitychange` (visible), `window.focus`.

- Пауза: `paused = true`, `audio.mute()`, если `state === 'play'` → `gameplayStop()`. Цикл продолжает рисовать (последний кадр + оверлей «Пауза»), `update` не вызывается. Из-за `dt = min(0.033, …)` скачка времени после возврата нет.
- Резюм: `paused = false`, `audio.unmute()`. Если `state === 'play'` — не запускаем сразу: `awaitTap = true`, рисуем «Тапни, чтобы продолжить»; первый тап снимает флаг, вызывает `gameplayStart()` и **не** считается прыжком. Для `title` и `dead` тап работает как обычно.
- Пауза во время показа рекламы игнорируется (`adBusy`), SDK сам управляет этим окном.
- Тест на дребезг: `blur` и `game_api_pause` могут прийти оба; вход в паузу идемпотентен.

## 9. Сохранения

Схема: `{ v: 1, best: number, coins: number }`. Будущие этапы добавляют поля, повышают `v` и пишут миграцию в `migrate(save)`.

Загрузка при старте: `cloud = await YG.getData()`, `local = JSON.parse(storage.teft_save)`, старые ключи `teft_best/teft_coins` — как ещё один источник. Итог — поле-по-полю максимум. Если итог отличается от облака или резерва — пишем туда. Причина выбора максимума: неавторизованный игрок, который потом залогинился, получает свой прогресс; потеря прогресса обиднее, чем редкое лишнее зачисление.

Запись: `persist()` — синхронно в резерв, асинхронно в облако, ошибки облака логируются в консоль и не мешают. Никаких записей чаще, чем раз в смерть/награду.

## 10. Локализация

`lang = YG.lang === 'ru' ? 'ru' : 'en'`. Все видимые строки через `T()`. Числа и единицы: `м` / `m`. Шрифт `system-ui` остаётся, кириллица и латиница в нём есть везде. Названия предметов в `FOOD/TRASH` (`name`) переезжают в таблицу строк по ключу вида `item.hair`.

## 11. Вьюпорт: десктоп и поворот

- Холст = размер окна (`innerWidth × innerHeight` × dpr). `scale = min(innerWidth/W, innerHeight/H)`. Поле шириной `W*scale` по центру по горизонтали, по вертикали тоже по центру.
- Область вне поля: `drawBg` рисует плитку на всю ширину холста (в координатах поля это отрицательные x и x > W), затемнённую на 35 %, и тонкие вертикальные линии на границах поля. Предметы и тефтеля клипуются полем.
- Тап вне поля по горизонтали трактуется как тап у ближайшего края поля (прыжок в ту сторону).
- Поворот телефона в landscape: тот же алгоритм, поле становится узким по центру. Отдельный экран «поверните телефон» не делаем; в консоли для мобильных выставим «портрет».
- `resize` вешается на `resize` и `orientationchange`.

## 12. Обработка ошибок

- SDK: любой сбой init/рекламы/данных → заглушка или «ничего не произошло». Игра никогда не встаёт из-за SDK.
- `AudioContext` может быть недоступен (уже обработано).
- Ошибки внутри `frame()` не перехватываем: smoke-тест обязан их находить до релиза.

## 13. Тестирование

- `node tools/smoke.js`: заглушка SDK с нулевыми задержками; сценарий: boot → титул → тап → 3000 кадров случайных тапов → форс-смерть → «Продолжить» (rewarded) → ещё смерть → «×2» → «Ещё раз» (interstitial) → 500 кадров → пауза/резюм → тап. Проверяет: нет исключений, `ready()` вызван ровно один раз, `start/stop` чередуются, `save.coins` после ×2 удвоился, `usedContinue` не даёт второго продолжения.
- `node tools/shot.js`: `title.png`, `play.png`, `results.png`, `paused.png`, `desktop.png` (окно 1280×720), `en_results.png`. Агент смотрит PNG глазами перед выдачей.
- `node tools/build.js`: собирает dist, проверяет что `dist/index.html` проходит smoke (тот же `_env.js`, но из dist).
- Ручной чеклист для владельца после появления черновика в консоли: sdk-dev-proxy, реальная реклама, сохранение при перезагрузке, пауза при сворачивании на телефоне.

## 15. Открытые вопросы к дизайнеру (не блокируют этап)

- Стартовая масса 1 делает первый волос смертельным. Предложение на этап 2: стартовая масса 2 или первые 8 м только еда.
- Показывать ли межстраничную рекламу на «Ещё раз», если игрок только что смотрел rewarded? По спецификации — нет (таймер 180 с сдвигает любой успешный показ). Если доход окажется низким, можно ослабить.
