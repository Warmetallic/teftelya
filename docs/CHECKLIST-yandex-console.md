# Чеклист владельца: черновик в консоли Яндекс Игр и живая проверка SDK

Агент не имеет доступа в консоль, поэтому этот проход делает владелец. Цель: убедиться, что реальный SDK
(реклама, сохранения, пауза) работает так же, как заглушка, и снять единственный непроверенный риск этапа 1.

## 1. Черновик игры
1. Консоль: https://games.yandex.ru/console → «Добавить игру».
2. Название «Тефтеля», категория «Аркады», устройства: **телефоны + десктоп** (ТВ не отмечать), ориентация: **портрет**.
3. Свежая сборка: `npm run build` → загрузить `dist/teftelya.zip` как черновик. **На модерацию не отправлять.**
4. Запомнить ID игры (число в адресе страницы игры в консоли). Черновик открывается по
   `https://yandex.ru/games/app/<ID>?draft=true`.

## 2. Локальный запуск через прокси Яндекса (можно править код и сразу проверять)
```
cd ~/myfolder/Games/teftelya && npm run build
npx @yandex-games/sdk-dev-proxy -p dist --app-id=<ID>
```
Прокси напечатает ссылку вида `https://yandex.ru/games/app/<ID>?draft=true&game_url=https://localhost:8080`.
Браузер спросит про самоподписанный сертификат localhost — разрешить.

## 3. Что проверить (десктоп)
- [ ] Титул появляется быстро, в консоли браузера (F12) нет красных ошибок.
- [ ] Debug-панель Яндекса (кнопка на странице черновика) показывает вызовы `LoadingAPI.ready`, `GameplayAPI.start` после тапа,
      `stop` после падения.
- [ ] Падение → «Продолжить»: идёт тестовый rewarded-ролик, после него тефтеля на тарелке внизу мигает.
- [ ] «Монеты ×2»: ролик, сумма удвоилась, у строки «Собрано за забег» отметка ×2.
- [ ] «Ещё раз»: первый рестарт без рекламы; межстраничная появляется не раньше 3 минут игры.
- [ ] Набрать монеты, обновить страницу: «Всего» сохранилось. Открыть в другом браузере под тем же аккаунтом Яндекса —
      монеты те же (облако).
- [ ] Свернуть вкладку во время забега: звук стих; вернуться — «Пауза», первый тап не тратит заряд.
- [ ] Растянуть окно: поле по центру, бока залиты плиткой, ничего не обрезано.

## 4. Что проверить (телефон)
- [ ] Открыть draft-ссылку в Яндекс Браузере и в приложении Яндекса: игра на весь экран, портрет.
- [ ] Долгий тап не выделяет текст и не открывает меню.
- [ ] Свернуть приложение в забеге и вернуться — «Пауза».
- [ ] Реклама и сохранения — те же пункты, что на десктопе.
- [ ] Отметить модель телефона и есть ли лаги при большой тефтеле (масса 10+).

## 5. Что прислать агенту
- ID игры, модель телефона, скриншоты или описание каждого несовпадения с пунктами выше,
  текст ошибок из консоли браузера, если были.
