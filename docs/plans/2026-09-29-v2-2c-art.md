# Тефтеля v2.2c «Арт тем» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Фон каждой из пяти тем — нарисованное место, увиденное глазами тефтели: задник-локация и огромные вещи-«герои»
на своих опорах, с лёгким размытием и параллаксом при подъёме; без картинок игра выглядит как раньше.

**Architecture:** Картинки (`assets/art/<тема>/*.webp`: бесшовный задник и вещи с прозрачным фоном) сгенерированы
локально и лежат рядом с `index.html`. `src/art.js` (между `game.js` и `render.js`) грузит их при старте, по теме
собирает слои в невидимые холсты — задник с тонировкой и светом ламп, вещи на опорах (кисти: стеклянные полки,
столешница, решётки духовки, дно мойки, край стола), размытый передний план — и рисует их с параллаксом; поверх
задника идёт лёгкое движение (пар, угольки, пузыри, огоньки). `drawBg` берёт арт темы, а если картинок нет — старый
фон. Запекание темы происходит на экране загрузки и при переходе на башню, не в первом кадре игры.

**Tech Stack:** Vanilla JS и Canvas 2D без бандлера. Node 22 для headless-тестов (`tools/_env.js`). node-canvas для
снимков, `sharp` (dev) — декодер WebP для них. Генерация картинок — вне репозитория (`~/myfolder/Games/sd-local`:
SDXL DreamShaper XL Lightning, rembg), в план входят только готовые `.webp`.

**Spec:** `docs/specs/2026-09-29-v2-2c-art-design.md`. Главнее спеки v2.2a §5 там, где расходятся.

## Как читать план

- План написан по прототипу. Каждую задачу сначала сделали во временной копии ветки: тесты, код, снимки, полный
  прогон `npm test`. В план вошёл только проверенный код, в том виде, в каком он лежит в коммитах прототипа.
- База задачи 1 — коммит `5502bee` (спека), база каждой следующей — результат предыдущей.
- Правка файла дана диффом: сохранить в файл и применить `git apply файл`. Новые текстовые файлы даны целиком.
  Картинки (`.webp`) бинарные — их шаг задачи берёт из локальной ветки прототипа `p22c-proto` командой
  `git checkout p22c-proto -- assets/art/<тема>`; ветка живёт до слияния плана, потом удаляется.
- Отбор картинок уже сделан по листам генератора (`sd-local/out/sheet_*.png`): в план входят выбранные.

## Global Constraints

- Спека v2.2c главнее v2.2a §5; правила v2.2a, v2.1.1 и v2 — где v2.2c молчит.
- Зависимости только вниз по порядку скриптов: `art.js` стоит между `game.js` и `render.js`, читает `camY`, `tGame`,
  `tower` и не пишет состояние игры; `main.js` зовёт `artPrepare`/`artWarm`.
- Имена картинок темы — ровно `ART_SRC[тема]` из `src/art.js`; файл `assets/art/<тема>/<имя>.webp`.
- Без картинок (Node, обрыв сети, старый браузер) `artBg` возвращает `false`, рисуется старый фон темы `BG_DRAW`;
  тесты не зависят от ассетов.
- Экран загрузки ждёт картинки первой темы не дольше `ART_WAIT_MS = 3000`; слои темы печёт `artPrepare` до первого
  кадра башни; остальные темы допекает `artWarm` между кадрами титула.
- Слои: задник `T 702, S 2, p 0.2`; вещи `T 2400, S 1.5, p 0.6, blur 2`; передний план `T 1600, S 1, p 1.35, blur 7,
  alpha 0.7`; размытие по вертикали по кругу — повтор без шва.
- Цвета игры (золото, оранжево-красный `#ff5a36`, жёлтый сыра) фон не берёт крупными пятнами; тёплые темы приглушены
  тонировкой «туманом глубины» при запекании.
- Бюджет картинок: ≤ 500 КБ на тему, ≤ 2.5 МБ всего; `dist/teftelya.zip` содержит `assets/`.
- Лицензии: картинки — OpenRAIL++ (модель) и Apache-2.0 (rembg), описано в `assets/art/README.md`.
- `npm test` — одиннадцать скриптов; ожидаемый шум — ровно два блока `YaGames.init failed, using stub …` от `test_sdk`.
- Каждый модуль заканчивается `expose({…})`; `Object.assign` для DBG не годится.
- Русские строки о Тефе без гендерных форм. Листы дизайна `shots/design_*.png` не перезаписывать.
- Порт 8080 занят BuildLocal: игровой сервер — только 8765, гасить после проверки.
- Коммиты с трейлером `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; слияние в `main` и push — только по «да» владельца.

## Review Focus

Случаи, которые спека подразумевает, но которые до подготовки плана не проверял ни один тест:

1. Переход на следующую башню другой темы: после «Дальше» слои новой темы испечены до первого кадра игры, а не с
   задержкой ≈ 0.4 с в нём (§6). Тест: задача 6, `tools/test_render.js`, «после artPrepare тема испечена, повторный
   вызов не печёт заново».
2. Десктоп и landscape (поле уже экрана, `fieldBounds().x0 < 0`): боковые зоны — ровный цвет темы под затемнением,
   без разрывов и без повторов слоёв; снимок `desktop` (§3). Проверка: задача 6, снимок `shots/desktop.png`.
3. Память телефона: пять тем × три слоя невидимых холстов; `artWarm` печёт все темы на титуле. Проверка: задача 6,
   тест «холсты слоёв темы не больше 6 МПкс, испечены не больше двух тем» (`tools/test_render.js`).
4. Смерть, «Продолжить», «С чекпоинта» и «Заново» не перезапекают слои темы: `ART[тема]` создаётся один раз (§6).
   Тест: задача 6, тот же, что в пункте 1.
5. Вещь темы с текстом или этикеткой, которую генератор не убрал (§11): в план входят только картинки без надписей —
   проверяется глазами по листам и снимкам `theme_*` в каждой задаче.

// размытие глубины резкости: три прохода box-blur ≈ гаусс в premultiplied alpha; по вертикали по кругу — слой повторяется без шва
function artBlur(g, w, h, r) {
  const img = g.getImageData(0, 0, w, h), d = img.data, n = w * h, ch = [0, 1, 2, 3].map(() => new Float32Array(n)), tmp = new Float32Array(n);
  for (let i = 0; i < n; i++) { const a = d[i * 4 + 3] / 255; ch[0][i] = d[i * 4] * a; ch[1][i] = d[i * 4 + 1] * a; ch[2][i] = d[i * 4 + 2] * a; ch[3][i] = d[i * 4 + 3]; }
  const k = 1 / (2 * r + 1);
  for (const c of ch) for (let pass = 0; pass < 3; pass++) {
    for (let y = 0; y < h; y++) { const o = y * w; let acc = 0; for (let i = -r; i <= r; i++) acc += c[o + Math.min(w - 1, Math.max(0, i))];
      for (let x = 0; x < w; x++) { tmp[o + x] = acc * k; acc += c[o + Math.min(w - 1, x + r + 1)] - c[o + Math.max(0, x - r)]; } }
    for (let x = 0; x < w; x++) { let acc = 0; for (let i = -r; i <= r; i++) acc += tmp[((i % h) + h) % h * w + x];
      for (let y = 0; y < h; y++) { c[y * w + x] = acc * k; acc += tmp[((y + r + 1) % h) * w + x] - tmp[(((y - r) % h) + h) % h * w + x]; } }
  }
  for (let i = 0; i < n; i++) { const a = ch[3][i], inv = a > 0.5 ? 255 / a : 0; d[i * 4] = ch[0][i] * inv; d[i * 4 + 1] = ch[1][i] * inv; d[i * 4 + 2] = ch[2][i] * inv; d[i * 4 + 3] = a; }
  g.putImageData(img, 0, 0);
}
