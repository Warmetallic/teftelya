# Тефтеля v2.2a «Темы башен и нижняя граница» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каждая башня первого круга ощущается иначе в первые десять секунд: своя тема, свой фон и своя уникальная платформа. Нижний край экрана — видимая смертельная полоса, под экраном больше не спастись.

**Architecture:** Новая таблица тем `src/themes.js` задаёт тему и круг по номеру башни. Поведение новых платформ живёт в `platforms.js` и возвращает события, `game.js` их применяет. Генератор башни сначала ставит лопасти, потом уникальности темы по правилам каждого типа, из отдельного потока случайных чисел. Бот `tools/bot.js` учится новым платформам и по-прежнему доказывает проходимость башен 1–100.

**Tech Stack:** Vanilla JS и Canvas 2D без бандлера. Node 22 для headless-тестов (`tools/_env.js`). node-canvas для снимков. `tools/build.js` собирает `dist/index.html` и `dist/teftelya.zip`.

**Spec:** `docs/specs/2026-09-25-v2-2a-themes-design.md`. Она дополняет спеки v2 и v2.1.1 и главнее их там, где они расходятся. Уточнения, найденные при подготовке плана, записываются в её §14 задачей 7.

## Global Constraints

- Спека v2.2a главнее спек v2 и v2.1.1 там, где они расходятся.
- Зависимости только вниз по порядку скриптов; модули ниже `game.js` возвращают события и не пишут его состояние (§9). `src/themes.js` встаёт перед `src/tower.js`.
- Темы по кругу: `themeFor(N) = THEMES[(N − 1) mod 5]` — кухня, холодильник, духовка, раковина, праздничный стол; круг `loopOf(N) = ⌊(N − 1) / 5⌋ + 1` (§3.1).
- Уникальности v2.2a: холодильник — полка, духовка — тостер, раковина — миска, праздничный стол — лопатка-батут с первого круга; кухня — доска с ножом со второго круга (§3.2).
- Нижняя граница: `BAND_H = 36` px, смерть «В пропасть!», когда `ball.y + ball.r > camY + H − BAND_H + BAND_SINK`, `BAND_SINK = 12` (§4).
- Плашка «Башня N · Тема» при старте башни на 1.5 с (§5).
- Полка: `SHELF_KEEP = 0.6`, `SHELF_FRICTION = 600` px/с² (§6.1). Тостер: `TOASTER_T = 1` с; тостер и лопатка подбрасывают на `LAUNCH_H = 420` px, `vx = 0`, заряды полные (§6.2, §6.4).
- Миска: первый тап отлепляет и тратит заряд (§6.3). Доска: `BOARD_W = 180`, нож в `BOARD_KNIFE = 25` px от края у стены, центр доски безопасен при любой массе (§6.5).
- `UNIQUE_SHARE = 0.2` обычных платформ, за счёт тарелок; старт, чекпоинты, крыша и площадки отдыха не заменяются (§7).
- Урон от уникальностей — один кусок, как от любой опасности.
- Все числа черновые (§13), но в коде ровно те, что в этом плане.
- `npm test` — одиннадцать скриптов; ожидаемый шум — ровно два блока `YaGames.init failed, using stub …` от `test_sdk`.
- Каждый модуль заканчивается `expose({…})`; `Object.assign` для DBG не годится.
- Русские строки о Тефе без гендерных форм.
- Листы дизайна `shots/design_*.png` не перезаписывать.
- Порт 8080 занят BuildLocal: игровой сервер, если нужен, — только 8765, гасить после проверки.

## Task 4. Тостер и лопатка-батут (спека §6.2, §6.4, §7)
