# Тефтеля — вертикальная аркада для Яндекс Игр

Один файл `teftelya.html`, без зависимостей и ассетов (~30 КБ). Открывается прямо в браузере.
Цель проекта: опубликовать на Яндекс Играх и получать доход с рекламы. Ожидания скромные.

## Роли
- Владелец репо — геймдизайнер, принимает решения по механике и виду.
- ИИ-агент — программист. Всё пишет, собирает и **проверяет рендером** (см. «Как проверять»).

## Концепция
Маленькая тефтеля прыгает вверх по бесконечной башне (стиль Doodle Jump / Flappy).
Ест еду — растёт, мусор и стены отрывают от неё фарш.
Оригинальный персонаж: никаких персонажей из существующих мультсериалов.

## Правила (актуальные, согласованы с дизайнером)
Одно чёткое деление: **еда — всегда хорошо, мусор — всегда плохо.**

- **Управление**: тап = прыжок вверх. Тап слева/справа от тефтели — прыжок в ту сторону.
  Клавиатура: стрелки / A D / пробел.
- **Прыжки — ресурс**: 4 заряда (`MAXJ`). Каждый прыжок тратит заряд. Еда возвращает:
  кетчуп +1, макароны +2, мясо +3. Без еды заряды копятся сами по одному за 1.6 с (`REGEN`) —
  чтобы падение было восстановимым, но лететь вверх без еды было нельзя.
- **Еда** (кетчуп +1 масса / 1 монета, макароны +1 / 2, мясо +2 / 5).
- **Мусор**: волос −1, грязь −2, муха −1 (двигается). Масса ниже 1 — проигрыш.
  При потере массы от тефтели физически отлетают куски фарша.
- **Стены**: удар на скорости > 260 (`WALL_HIT`) отрывает 1 массу.
- **Масса даёт**: множитель монет (5 → ×1.5, 9 → ×2, 13 → ×2.5); с массы 6 (`HAIR_PROOF`)
  волосы не наносят урона («пф»); инерцию — большая тефтеля хуже слушается и сильнее колышется.
- **Сила прыжка от массы НЕ зависит** — ритм тапов одинаковый всю игру.
- Сложность растёт с высотой: доля мусора и плотность предметов.
- Проигрыш: масса < 1 или улетела за нижний край (камера едет только вверх).

## Отвергнутые идеи (не возвращать без обсуждения)
- **Кликер/idle** — изначальный жанр, заменён аркадой: больше точек для rewarded-рекламы.
- **Unity WebGL** — тяжёлые сборки, Яндекс штрафует за загрузку; агент не может собрать.
- **«Тяжелее = кликай чаще»** — treadmill, наказание за рост. Убрано.
- **Переедание / икота** — превращало еду в «хватай, но не слишком». Убрано целиком
  (в коде остались безобидные поля `full`, `hiccup`, можно вычистить).
- **Гладкий коричневый шар** как персонаж — читается как какашка. Теперь тефтеля —
  скопление шариков и овалов фарша с бугристым силуэтом, соусом и петрушкой.

## Устройство кода (`teftelya.html`, один IIFE)
- `resize()` — логический холст 480×854, масштабируется в окно.
- `audio/tone/sfx` — звуки синтезируются WebAudio, файлов нет.
- `FOOD`, `TRASH` — каталог предметов (радиус, масса, монеты, заряды, вес спавна).
- `ball` + `initBody/deform/squash/pulse/jolt/updateBody` — мягкое тело: 26 точек на пружинах,
  жёсткость и демпфирование падают с массой (`heavy()`), лаг от скорости даёт джиггл.
- `reset/spawn/eat/loseMeat/wallHit/die/update` — игровая логика.
- `drawBg/drawItem/chunk/drawBall/drawHUD/panel/draw` — рендер.
  `drawBall` строит список шариков фарша (наружное кольцо + внутренние), сортирует по z,
  рисует тёмную подложку (щели), сами шарики, соус, петрушку, лицо.
- `window.__dbg = { ball, camY }` — хук для отладочных рендеров.
- Сохранения best/coins — `localStorage` в try/catch (заменить на Yandex SDK).

## Как проверять (обязательно перед выдачей визуала)
В `tools/` лежат скрипты для headless-запуска в Node:
- `node tools/smoke.js` — прогоняет игровой цикл с тапами, ловит runtime-ошибки.
- `node tools/shot.js` — рендерит скриншоты через `node-canvas` (`npm i canvas`).
Агент должен **смотреть на PNG**, а не описывать код: дважды визуал уходил непроверенным и был не тем.
